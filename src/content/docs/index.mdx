## Architectural Pillars

<CardGrid stagger>
  <Card title="Zero-Open-Port Ingress" icon="seti:lock">

  <Card title="Tailscale WireGuard Mesh" icon="seti:graphql">

  </Card>
  <Card title="Apple Silicon PaaS Powerhouse" icon="apple">

## What You'll Learn

1. **Hardened Cloud Gateway Setup:** Deploying an OCI Always Free ARM Ampere instance with custom Caddy builds, Cloudflare DNS-01 wildcard certificates, and HTTP/3 QUIC support.
2. **End-to-End Mesh Security:** Bridging cloud reverse proxies to internal subnets using Tailscale with iptables/nftables packet filtering and UFW.
3. **Container Orchestration with Coolify:** Managing production Docker workloads without vendor lock-in on energy-efficient Apple Silicon hardware.
4. **GitOps & Observability:** Automatically validating Caddyfiles with automated CI tests, deploying via SSH GitHub Actions, and monitoring service health with Uptime Kuma and Gotify push alerts.
